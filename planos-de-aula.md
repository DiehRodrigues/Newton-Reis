# Planos de Aula - Missões Matemáticas - EMEF Newton Reis

## Conceito
Atividades gamificadas em dupla onde os alunos resolvem problemas do cotidiano usando ferramentas online do site calculey.com. O aluno acessa o site, explora o conteúdo, usa as ferramentas e volta ao site da escola para o próximo comando.

## Estrutura de cada Missão (1 aula = 45-50 min)
- **Abertura (5 min):** Professor apresenta o contexto da missão
- **Investigação (25-30 min):** Dupla acessa calculey.com e resolve os problemas encadeados
- **Registro (5-10 min):** Dupla anota respostas finais
- **Fechamento (5 min):** Discussão coletiva dos resultados

## Fluxo do Aluno
```
SITE DA ESCOLA → lê Etapa 1 → acessa calculey.com → resolve → volta
SITE DA ESCOLA → lê Etapa 2 → acessa calculey.com → resolve → volta
SITE DA ESCOLA → lê Etapa 3 → acessa calculey.com → resolve → volta
SITE DA ESCOLA → resposta final / desafio bônus
```

## Turmas Participantes
- **5º Ano** - Foco: cotidiano, frações, porcentagem, introdução a poupar
- **6º Ano** - Foco: geometria prática, planejamento, primeira poupança
- **8º Ano** - Foco: empreendedorismo, juros, engenharia, sustentabilidade

## Missões Planejadas

### 5º Ano
1. **Missão: O Aniversário da Turma** (Idade → Porcentagem → Frações)
2. **Missão: A Festa Junina da Escola** (Porcentagem → Frações → Média → Regra de 3)
3. **Missão: Meu Primeiro Cofrinho** (Porcentagem → Regra de 3 → Média → Frações)

### 6º Ano
1. **Missão: Reformando a Sala de Aula** (Perímetro → Área → Porcentagem → Regra de 3)
2. **Missão: Viagem de Estudo ao Parque** (Regra de 3 → Porcentagem → Frações → MMC)
3. **Missão: Minha Primeira Poupança** (Porcentagem → Regra de 3 → Média → Potenciação)

### 8º Ano
1. **Missão: Montando Meu Primeiro Negócio** (Porcentagem → Equação 1º Grau → Regra de 3 → Juros Simples)
2. **Missão: Planejando o Futuro** (Juros Simples → Juros Compostos → Porcentagem → Equação 1º Grau)
3. **Missão: Engenheiro por um Dia** (Pitágoras → Área → Volume → Regra de 3)
4. **Missão: Consumo Consciente** (Economia de Água → Porcentagem → Regra de 3 → Juros Compostos)

## Regras de Implementação
- Sempre em dupla
- Primeira missão de cada turma deve ser SIMPLES (2-3 etapas) para entender a dinâmica
- Resultados de uma etapa alimentam a próxima (encadeamento)
- Aluno acessa calculey.com diretamente e pesquisa o tema dentro do site
- Não usar a palavra "calculadora" - usar "ferramenta online"
- Incluir instrução para ler conteúdo do site antes de resolver
- Associar a ODS, BNCC e Currículo da Cidade de SP (Tecnologia)
